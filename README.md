# 📱 Indian Kids Screen Time Dashboard  

---

## 1. Project Title / Headline  
**Indian Kids Screen Time Insights Dashboard**  
An interactive Power BI dashboard analyzing kids’ screen usage in India, focusing on device preferences, gender-wise usage, and health impacts.  

---

## 2. Short Description / Purpose  
The Indian Kids Screen Time Dashboard provides insights into children’s digital habits across India. It highlights **average screen time by gender**, **most used devices**, and **health issues** like poor sleep and eye strain.  
This tool can be used by **parents, educators, and policymakers** to understand the effects of excessive screen usage on kids’ health.  

---

## 3. Tech Stack  
The dashboard was built using the following tools and technologies:  

- 📊 **Power BI Desktop** – Main data visualization tool for dashboard creation.  
- 🔄 **Power Query** – Data transformation & cleaning (handling null values, duplicates, converting hours → minutes).  
- 🧮 **DAX (Data Analysis Expressions)** – Used for calculated measures like average screen time and gender splits.  
- 🗂 **Excel/CSV** – Dataset storage and preprocessing.  

---

## 4. Dataset  
- **Total Kids:** ~9.7K  
- **Columns:** Gender, Age, Location (Urban/Rural), Primary Device, Avg Daily Screen Time, Health Impacts  
- Data was cleaned and transformed before visualization.  

---

## 5. Dashboard Features  
✅ **KPI Cards** → Total Kids, Male vs Female, Most Used Device  
✅ **Bar Chart** → Health Impacts (Poor Sleep, Eye Strain, Anxiety, etc.)  
✅ **Pie Charts** → Kids by Gender, Primary Device Distribution  
✅ **Bar Chart** → Avg Screen Time by Gender  
✅ **Filters** → Device Type, Gender, Urban/Rural  

---

## 6. Key Insights  
- 📱 **Smartphones** are the most used device (46%).  
- 🛌 **Poor Sleep** is the top health issue (2.2K kids affected).  
- 👦👧 Screen time is nearly equal across genders (260–263 mins).  
- 🌆 Urban kids show slightly higher dependency on gadgets.
